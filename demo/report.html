LLM 與 Agent 模型比較

雲端 API 與本機 GGUF 共用工作負載。各測試路徑分開呈現；本報告不是官方 MLPerf 成績。雲端時間包含網路與服務排隊，本機時間包含 HTTP 與推論。

TTFT 是首個可見文字片段的等待時間。Native TPS 是估計值，tokenizer 不同；串流片段不等於單一 token。— 代表無資料或不適用。品質檢查與語意品質不同；重播不提供任務成功率。
